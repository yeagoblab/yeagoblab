### Sobre mí

Curso **Sistemas Microinformáticos y Redes (SMR)**. Aprendo practicando: monto un servidor casero, hago juegos en el navegador y pruebo herramientas con IA que corre en mi propio equipo. Aquí subo lo que ya está lo bastante limpio como para enseñarlo.

### Estoy aprendiendo

- **Linux y servidores:** Ubuntu Server, systemd, usuarios, SSH, cortafuegos (ufw).
- **Redes y servicios:** DNS, DHCP, VPN mesh (WireGuard) y túneles.
- **Desarrollo web ligero:** HTML, CSS y JavaScript sin dependencias.
- **Seguridad básica:** auditar mi propio sistema y entender las amenazas.

### Montado en mi homelab

- Contenedores con Docker y Docker Compose.
- Monitorización, avisos y registros de servicios.
- DNS propio y acceso remoto privado.
- IA local: modelos de lenguaje, voz, imagen y música en mi propio equipo.
